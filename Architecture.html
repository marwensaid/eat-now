🍽️ Architecture EatNow

Application de Restauration - Architecture Microservices Cloud-Native

Menu Service - Gestion catalogue
Order Service - Gestion commandes
Delivery Service - Gestion livraisons
HPA - Auto-scaling
Prometheus - Métriques
Grafana - Visualisation

📝 Notes d'Architecture

  • Scalabilité: HPA configuré pour scaler entre 2 et 5 replicas basé sur l'utilisation CPU (70%) et mémoire (80%)
  • Résilience: Circuit Breaker, Retry avec backoff exponentiel, et Timeout de 2s sur tous les appels inter-services
  • Observabilité: Toutes les métriques exposées via /actuator/prometheus et collectées par Prometheus
  • Health Checks: Liveness et Readiness probes configurées pour tous les services
  • Documentation: Swagger UI disponible sur /swagger-ui.html pour chaque service
  • Stockage: Données en mémoire (ConcurrentHashMap) - pas de base de données externe requise
