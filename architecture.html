📚 Stack Technique

  • Runtime: Java 17
  • Framework: Spring Boot 3
  • Résilience: Resilience4j
  • Documentation: OpenAPI/Swagger
  • Monitoring: Prometheus + Grafana
  • Container: Docker + Kubernetes

🔍 Légende

  • Ingress: Point d'entrée unique pour le trafic externe
  • Services: Microservices Spring Boot avec scalabilité automatique (HPA)
  • Resilience4j: Gestion de la résilience avec Circuit Breaker, Retry, et Timeout
  • Prometheus: Collecte des métriques
  • Grafana: Visualisation des métriques et dashboards
  • → Ligne pleine: Communication synchrone REST
  • ⟶ Ligne pointillée: Flux de métriques
